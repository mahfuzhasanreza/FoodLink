### Environment Variables

Create a `.env.local` file in the root directory of the project and add the following Firebase configuration:

```env
VITE_apiKey=YOUR_FOODLINK_API_KEY
VITE_authDomain=YOUR_FOODLINK_AUTH_DOMAIN
VITE_projectId=YOUR_FOODLINK_PROJECT_ID
VITE_storageBucket=YOUR_FOODLINK_STORAGE_BUCKET
VITE_messagingSenderId=YOUR_FOODLINK_MESSAGING_SENDER_ID
VITE_appId=YOUR_FOODLINK_APP_ID
```
